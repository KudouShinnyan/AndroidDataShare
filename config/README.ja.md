# config リスト説明

[简体中文](README.md) · [繁體中文](README.zh-Hant.md) · [English](README.en.md) · [日本語](README.ja.md)

編集するのはこれらの .txt のみで、反映には再ビルドが必要です。このファイルは APK には同梱されません。
パッケージ名は大文字小文字を区別します。確認できたものだけを追加し、出典はリストのコメントではなく PR の説明に書いてください。

## 書式
UTF-8；`#` はコメント；項目の区切りは 空白 / カンマ / セミコロン；ビルド時に順序を保ったまま正規化・重複除去します。

## desync_groups.txt · 回避
1 行 = 互いに共有すべきでないパッケージの組。主アプリと対象が同じ行に含まれ、別パッケージなら回避警告を出します（警告のみで、共有は禁止しません）。

    com.gof.global com.gof.china

## sync_groups.txt · 共有可
1 行 = 更新が同期しており、同じデータを再利用できると確認済みの組。主アプリが同じ行のいずれかに一致した場合、その行の残りのパッケージは行内順に対象アプリの選択画面の先頭に固定されます（固定のみで、自動選択はしません）。主アプリと対象が同じ行に含まれ、別パッケージなら → 一般通知のみを省略し、静かに扱います。

    com.miHoYo.Yuanshen com.miHoYo.GenshinImpact com.miHoYo.ys.bilibil

共有を保証するものではありません。マウントのリスク、実読による確認、バージョン検出、自動終了、取り消し処理はすべて適用されます。誤記は警告を 1 回静かに減らすだけなので、確認済みの名前だけを書いてください。

## containers.txt · コンテナ
1 行 = コンテナのパッケージ名 + 対象アプリのディレクトリテンプレート。`{pkg}` は対象アプリのパッケージ名で、複数回現れることがあり、スキャン時にすべて置換します。書式はリスト先頭のコメントを参照。

    top.bienvenido.saas.i18n /sdcard/Android/obb/top.bienvenido.saas.i18n/scopedStorage/{pkg}/Android/data/{pkg}/

ディレクトリは `/sdcard/Android/obb/<コンテナ>/`、`/sdcard/Android/data/<コンテナ>/` または `/data/data/<コンテナ>/` の下のいずれかにあることがあります。既知のコンテナを 1 行既定で内蔵しています（下の行）。他のコンテナは別の行に追加します。
スキャンは最初の `{pkg}` で前後に分け、接頭辞の直下にある 1 階層のサブディレクトリを列挙し、そのディレクトリ名を候補パッケージとして `{pkg}` をすべて置換し、生成されたディレクトリが存在する場合だけ候補に挙げます。
コンテナがいずれかのユーザーにインストールされていれば項目を表示し、名称はグループ設定のユーザーでのアプリ名、取得できなければパッケージ名にフォールバックします。

## 優先順位
回避 > 共有可による省略 > 一般通知。同じ組が回避と共有可の両方に入るとビルド警告（失敗にはなりません）、実行時は回避が優先です。コンテナリストはこの判定に参加しません。

## 提出
`assembleRelease` が `genDesync` を自動実行します（Gradle プロセス内、Windows 可、シェル不要）。`scripts/gen_desync.sh` は同じ規則の独立ツールです。
変更するのは `config/*.txt` のみ。`res`、Java、engine、ルート README には触れず、`genDesync` のタスク名と出力先も変えないでください。
確認点：解析できること、一致判定が想定通りであること、ビルドログに重複警告が出ていないこと。
