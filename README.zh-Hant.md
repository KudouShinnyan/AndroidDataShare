# AndroidDataShare

[简体中文](README.md) · [繁體中文](README.zh-Hant.md) · [English](README.en.md) · [日本語](README.ja.md)

主應用程式已經下載好資源包，不想給每個分身或多使用者再下一遍時，用本應用程式把 Android/data/<包名> 裡的資料共享過去，省下重複下載與幾 GB 佔用。

## 前提

本應用程式只是設定工具，執行共享至少需要 Shizuku 授權；純 Shizuku 只能複製，且一般僅限使用者 0 的 /storage/emulated/0 路徑，少數被設為私有權限的目錄仍會失敗；Sui / root 還能硬連結和掛載。Releases 只發佈一個 APK。開機恢復模組按需產生、手動刷入一次，僅用於掛載群組的重新開機恢復；硬連結與複製落盤，重新開機後天然保留，不依賴模組。不常駐、不偵測版本，版本變化由本應用程式比對基準。

## 使用

裝好 APK → 在主介面「執行權限」選後端並點「要求權限」→ 新增群組、選主應用程式與共享目錄、新增目標 → 儲存即套用。未授權時設定與儲存不可用，避免設定了卻無法生效。共享方式按實際情況選硬連結 / 複製 / 掛載，群組內可隨時切換，刪除群組會一併撤銷共享。

掛載群組需要重新開機後自動恢復時，點主介面的產生按鈕，把得到的 zip 在 Magisk / KernelSU / APatch 裡從本機安裝；不刷模組也能正常使用，硬連結與複製群組無需這一步；只是掛載群組重新開機後需開啟本應用程式補掛一次。

## 注意

- 兩端資源版本與更新進度要一致。若不同步，三檔都無法對齊，請不建立共享、讓兩端各自下載與更新。
- 硬連結只佔一份空間，主應用程式更新後不會跟過來，點「重新共享」重建；複製是獨立副本，多佔一份空間，同樣不跟更新；掛載的目錄內檔案會自動跟隨，但不一定按預期生效，是否生效以目標應用程式身份實讀為準。共享目錄由你勾選，帳號或登入狀態檔案若在其中，也會一併共用或清空，請先確認。
- 部分裝置與系統組合尚未逐一驗證；連網遊戲的反作弊與帳號風險由使用者自行承擔，重要資料請先在本機確認。
