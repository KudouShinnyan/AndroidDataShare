AndroidDataShare ディレクトリの説明

ここには以下のファイルが置かれることがあります。インストール後すぐ見られます。

AndroidDataShare-module.zip   モジュールzip。書き込む用、そのままで
linkstate.json                実行状態。アプリが書きます、変更しないでください
run.log                       直近の実行記録、閲覧・削除できます
containers.txt                コンテナのパッケージ名とデータパス、追記できます
sync_groups.txt               データを共有できるサーバーの組、追記できます
desync_groups.txt             分けておきたいサーバーの組、追記できます

# で始まる行はコメントと例で、反映されません。
アプリ内蔵のリストも読みます。ここは補足だけです。食い違う場合は内蔵の方を優先します。
このファイルは説明用です。ここにメモを残さないでください。
