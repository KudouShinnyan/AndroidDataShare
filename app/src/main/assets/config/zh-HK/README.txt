AndroidDataShare 目錄說明

這個目錄裡可能會有以下檔案，裝完就能看這份說明。

AndroidDataShare-module.zip   模組包，刷入用，不用改
linkstate.json                執行狀態，程式自己寫，別改
run.log                       最近一次執行的紀錄，可看可刪
containers.txt                容器套件名與資料路徑，可補充
sync_groups.txt               可共用的一組服，可補充
desync_groups.txt             需避開的一組服，可補充

名單裡 # 開頭的是註解和範例，不生效。
應用程式內建的名單也讀，這裡只作補充；兩邊寫得不一樣時，以內建的為準。
這份只作介紹，別在這裡記東西。
