AndroidDataShare directory

These files may appear here; this note is available right after install.

AndroidDataShare-module.zip   Module zip, flash it, leave as is
linkstate.json                Runtime state, written by the app, leave as is
run.log                       Log of the latest run, safe to view or delete
containers.txt               Container package names and data path, add your own
sync_groups.txt               Server groups that can share data, add your own
desync_groups.txt             Groups to keep apart, add your own

Lines starting with # are comments and examples, not active.
The built-in lists are read too; this is only a supplement. If they disagree, the built-in ones win.
