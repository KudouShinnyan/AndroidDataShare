AndroidDataShare 目录说明

这个目录里可能会有以下文件，装完就能看这份说明。

AndroidDataShare-module.zip   模块包，刷入用，不用改
linkstate.json                运行状态，程序自己写，别改
run.log                       最近一次执行的记录，可看可删
containers.txt                容器包名和数据路径，可补充
sync_groups.txt               可共用的一组服，可补充
desync_groups.txt             需避开的一组服，可补充

名单里 # 开头的是注释和示例，不生效。
应用自带的名单也读，这里只作补充；两边写得不一样时，以自带的为准。
这份只作介绍，别在这里记东西。
