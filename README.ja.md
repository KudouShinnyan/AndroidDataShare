# AndroidDataShare

[简体中文](README.md) · [繁體中文](README.zh-Hant.md) · [English](README.en.md) · [日本語](README.ja.md)

主アプリがリソース一式をダウンロード済みなら、同じゲームの別サーバー（別パッケージ）、別ユーザーへのインストール、コンテナ／クローンアプリでそのコピーを共有でき、再ダウンロードか数 GB の容量を省けます。

## 前提

これは設定ツールです。共有の実行には最低限 Shizuku が必要です。純 Shizuku では「コピー」のみで、通常はユーザー 0 の /storage/emulated/0/ に限られ、私有権限が設定された一部のディレクトリは失敗します。Sui / root ではさらにハードリンクとマウントも使えます。配布物は APK 1 つだけです。起動復元モジュールは必要時に生成し、1 度導入すればマウントグループの再起動後復元だけを行います。ハードリンクとコピーはディスク上に残るため再起動後もそのまま使え、モジュールは不要です。常駐せずバージョン確認も行わず、基準比較は本アプリが行います。

## 使い方

APK を入れ、ホーム画面の「実行権限」でバックエンドを選び「権限をリクエスト」を押してから、グループを作り、主アプリと共有ディレクトリを選び、対象を追加して保存します。権限が付与されるまで設定と保存は無効で、実行できない状態のまま設定されることはありません。方式はハードリンク / コピー / マウントからゲームに合わせて選び、後から切り替えられます。グループを削除すると共有も取り消されます。

マウントグループを再起動後に自動復元したい場合は、ホーム画面の生成ボタンで作った zip を Magisk / KernelSU / APatch でローカルからインストールします。モジュールがなくても通常通り使えますが、ハードリンクとコピーのグループにこの手順は不要です。マウントグループだけは再起動後に本アプリを開いて再適用する必要があります。

## 注意

- 両側のリソース版本と更新進度を揃えてください。同期できない場合、どの方式も版本を揃えられません。共有を作らず、それぞれ個別にダウンロード・更新させてください。
- ハードリンクは容量を増やさず、主アプリの更新には追従しないため「再共有」で作り直します。コピーは独立した複製で余分に容量を使い、同じく更新には追従しません。マウントしたディレクトリ内のファイルは自動的に追従しますが、期待どおりに生效しない場合があります。実際に効いているかは対象アプリ権限での読み取りで確認し、コマンド成功は証拠になりません。共有するディレクトリは利用者が選択するため、アカウントやログイン状態のファイルが含まれていれば一緒に共有・消去されます。事前に確認してください。
- 全ての端末・システムの組み合わせは検証済みではありません。オンラインゲームのアンチチートとアカウントのリスクは利用者の責任です。重要なデータの前にご自身の端末で確認してください。
